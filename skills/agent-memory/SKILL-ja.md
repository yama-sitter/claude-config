# Agent Memory — 日本語ミラー

> このファイルは人間用の参照ドキュメントです。Claude は英語版 `SKILL.md` を読みます。

## 目的

セッションをまたいで知識を保持するための永続メモリスペース。`~/.agent-memory/` に Markdown ファイルとして保存する。

## いつ使うか / 使わないか

**使う場面:**
- ユーザーが「覚えておいて」「保存して」「前回の話は？」などと言ったとき
- セッション中に後続セッションでも有用な発見をしたとき（プロアクティブ保存）

**使わない場面:**
- 今のセッション内にしか意味のない一時的な状態管理（タスクや変数）
- コード自体から読み取れる情報（ファイルパス・アーキテクチャ等）

## サブコマンド

| 引数 | アクション |
|---|---|
| `save [説明]` | Save Workflow — `[説明]` をトピックヒントとして使用 |
| `search <クエリ>` | Search Workflow — キーワードで検索 |
| `search` (引数なし) | 対話的にスコープ → トピックを絞り込み |
| 引数なし | 会話コンテキストから保存か検索かを推定 |

## 設計意図

- **保存はサブエージェントに委譲**: Write ツールの出力をメインコンテキストに流さないための設計。サブエージェントが整形・書き込みを担当し、親は抽出・判断のみ
- **フロントマターの `summary` が検索の鍵**: `rg "^summary:"` でスキャンするため、summaryだけで「読む価値があるか」が判断できる具体性が必要
- **ディレクトリ構造**: `<スコープ>/<YYYY-MM-DD>_<トピック>/<ファイル名>.md` — スコープはリポジトリ名または `general`

## フォルダ構造例

```text
claude-config/
└── 2026-05-12_bilingual-doc-management-design/
    └── design.md
general/
└── 2026-01-20_docker-compose-networking-tips/
    └── finding.md
```

## 保存すべき内容の判断基準

保存する: 発見に調査コストがかかったもの、非自明なパターン、トリッキーな問題の解決策、アーキテクチャ上の判断とその理由、後で再開予定の進行中の作業

保存しない: コードパターン・規約・ファイルパスなどコードから読み取れるもの、git履歴から分かること、CLAUDE.mdに書いてあること
