# Analyze — 日本語ミラー

> このファイルは人間用の参照ドキュメントです。Claude は英語版 `SKILL.md` を読みます。

## 目的

データドリブンな意思決定を支援するインタラクティブな「壁打ち相手」スキル。ユーザーが分析者であり、スキルは多角的な反応を提供して思考を研ぎ澄ます役割を担う。

## いつ使うか / 使わないか

**使う場面:**
- データの意味を掘り下げたいとき（KPI、ファネル、コホート、定性フィードバック等）
- 非自明な含意を導き出したいとき
- 次のアクションをデータから決定したいとき

**使わない場面:**
- 顧客行動からJTBDを抽出したいとき（→ dex）
- リサーチ計画やインタビューガイドを設計したいとき（→ research）

## サブコマンド

| 引数 | アクション |
|---|---|
| `start [トピック]` | 新しいスパーリングセッションを開始 |
| `[質問]` | セッションを継続（ラリーごとに新規SAを起動） |
| `end` | セッションを終了し要約を生成 |

## 設計意図

- **ラリーごとに新規SA**: 各 `/analyze [質問]` で新しい `general-purpose` SAを起動。SAのコンテキストはスパーリングプロンプトが支配し、命令の顕著性を高める
- **スナップショット + スライディングウィンドウ**: 状態はポイントインタイムのスナップショット + 直近3ラリーのフルテキスト。セッションが長くなってもサイズが増えない
- **コンテキスト純粋性**: SAのコンテキストはスパーリングプロンプト・スナップショット・直近ラリー・現在の質問のみ。CLAUDE.md・ツール定義・無関係な会話履歴は含まない
- **ライフサイクルI/OはWriter SA**: セッションファイルの作成（start）と終了（end）は専用のwriter SAに委譲し、親コンテキストからI/O出力を排除

## ユーザーの役割

ユーザーが分析者。スキルは「壁打ち相手」として多視点の反応を提供するが、解釈と判断はユーザーが行う。
