# Git — 日本語ミラー

> このファイルは人間用の参照ドキュメントです。Claude は英語版 `SKILL.md` を読みます。

## 目的

Git 操作をガイドライン強制付きで実行するスキル。ブランチ作成・コミット・プッシュ・PR作成・ブランチ整理をサブコマンドで提供する。

## いつ使うか / 使わないか

**使う場面:**
- コミット・プッシュ・PR作成・ブランチ作成・不要ブランチの整理

**使わない場面:**
- worktree操作 → `tree` スキルを使う

## サブコマンド

| コマンド | 説明 |
|---|---|
| `/git branch [説明]` | ブランチ名を生成して作成 |
| `/git commit` | 変更をステージしてコミット |
| `/git push` | 現在のブランチをリモートにプッシュ |
| `/git pr` | プルリクエストを作成 |
| `/git prune` | リモートで削除済みのローカルブランチを削除 |
| `/git` (引数なし) | サブコマンド一覧を表示 |

## 設計意図

- **ガイドライン強制**: `rules/git-guidelines.md` を `@`インポートで自動読み込み。全サブコマンドでルールが適用される
- **commit の3段階ガード**: シークレットファイルの排除 → 変更グループ分け → Verification実行 → コミット
- **PR テンプレート自動検出**: `.github/pull_request_template.md` を検索して使用
- **No force operations**: `--force` プッシュは一切使わない
- **worktreeは別スキル**: ブランチ作成はリポジトリ内で行い、worktreeは `tree` スキル（EnterWorktree/ExitWorktree）が担当

## ガイドライン参照先

`rules/git-guidelines.md` にブランチ命名規則・コミットメッセージ形式・禁止事項が定義されている。スキルの設計を変更する際はガイドラインとの整合性を確認すること。
