# Kaizen — 日本語ミラー

> このファイルは人間用の参照ドキュメントです。Claude は英語版 `SKILL.md` を読みます。

## 目的

Claude Code の失敗を分析し、構造的・システム的な改善を設計・実装するスキル。一度限りのバグ修正ではなく、同じ失敗が起きない仕組みをハーネスに組み込む。

## いつ使うか / 使わないか

**使う場面:**
- ユーザーが Claude Code の意図しない動作に気づいたとき

**使わない場面:**
- シンプルなバグ修正や実装タスク

## サブコマンド

| 引数 | アクション |
|---|---|
| (デフォルト) | フルプロセス（分析 → アイデア → 確認 → 実装 → 記録） |
| `diagnose` | 分析とアイデア提示のみ。実装しない |
| `plan` | 承認済みプランを agent-memory に保存。セッションをまたいで実行可能 |
| `apply [path]` | 改善を実装。path があればプランファイルから、なければ会話から |
| `commit` | kaizen の変更を claude-config リポジトリにコミット |

## 設計意図

- **サブエージェントによる分析**: フルプロセスはサブエージェントが分析〜実装をエンドツーエンドで実行
- **構造的改善にフォーカス**: 個別の修正ではなく、同じ失敗が繰り返されない仕組みをハーネス（hooks・rules・CLAUDE.md）に組み込む
- **セッションをまたげる設計**: `plan` サブコマンドで agent-memory に保存し、別セッションで `apply` できる
- **harness-catalog.md**: `references/harness-catalog.md` にハーネス改善の選択肢カタログが記載されている。設計の選択肢を検討する際に参照する（→ 日本語ミラー候補）

Claude Code ハーネスの構成要素:

- `rules/*.md` のルール
- `CLAUDE.md` の指示
- スキル（`skills/*/SKILL.md`）
