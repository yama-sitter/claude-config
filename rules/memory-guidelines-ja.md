## ルール

- メモリの保存・検索・整理には常に `agent-memory` スキル（`/agent-memory`）を使用する
- auto memory ディレクトリ（`memory/`）には直接書き込まない。agent-memory スキルへのポインタとしてのみ使用する
- 保存時は agent-memory スキルのフォルダ構造とフロントマターフォーマットに従う

> **Rationale**: `memory/` への直接書き込みを禁止することで、メモリの管理経路を `agent-memory` スキルに一元化する。フォルダ命名規則・frontmatter 形式の統一により、将来の検索・参照が容易になる。

## 計画書の agent-memory への保存

計画書を自動的に agent-memory に保存しない。ユーザーが明示的に指示した場合のみ保存する。

保存手順（指示された場合）：

- スコープ：現在のリポジトリ名
- ディレクトリ名：`<YYYY-MM-DD>_<タスク説明>-plan`
- ファイル名：`plan.md`
- メモリに含める内容：タスクの目標、実装アプローチ、主要ファイル、検証ステップ
- 関連する計画メモリがすでに存在する場合は、新規作成せずに更新する

> **Rationale**: 計画を自動保存すると、検討途中の不完全な計画や却下された計画がメモリに残ってしまう。ユーザーの明示的な指示がある場合のみ、承認済みの確定した計画を保存する。
